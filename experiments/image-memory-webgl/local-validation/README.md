# Reconstructed image-alpha local validation

This is a newly reconstructed candidate, not a byte-identical recovery of the earlier unsaved experiment. The public product patch changes only render/src/utils.rs. Experimental >=262144 decoded pixels use validate-alpha, exact RGB expansion, then alpha replay; smaller images keep the original branch. It is a memory/latency tradeoff candidate, not a new app mode or released default.

## Reproduction
Use matching official Rust 1.99.1 host and wasm32-unknown-unknown libraries, Node 24.22.1 and Pillow 13.0.0. Reconstruct the official baseline from ../source-binding.json and the existing lazy-Graphic six-patch chain. Copy the full baseline into a sibling `candidate/` directory here, apply ../product.patch there, then copy baseline render/src/utils.rs into candidate/render/src/baseline_utils.rs and append `pub mod baseline_utils;` to candidate/render/src/lib.rs. These last two changes are harness-only; they are not in the product patch. Keep original Cargo.lock unchanged.

Run `python generate.py`, compare regenerated files against fixture-hashes.json, then build harness/Cargo.toml with `cargo build --locked --release` and the same command with `--target wasm32-unknown-unknown`. Run `python host_test.py` and `node run.mjs`. The standalone harness lock preserves every dependency name/version/source/checksum from the original lock; the probe root is the only new package. To run render unit tests without resolving the full desktop/web workspace, use a separate source copy with workspace members render, swf, wstr, render/pixel_bender and render/naga-agal; preserve all locked dependency identities. The measured candidate source must match ../source-binding.json.

## Checks and interpretation
37 actual JPEG decoder pairs compare all output bytes, format, dimensions and exact error Debug text separately on each platform. Host and WASM pixel hashes differ for valid JPEGs in these fixtures; cross-platform pixel identity is not claimed or used as an oracle. Both original and candidate agree within each platform. Cases cover RGB, grayscale, CMYK, threshold sides, transparent/random/opaque alpha, no alpha, empty/short/long, corruption, checksum failure, accepted truncation, trailing and concatenated streams, invalid JPEG. 54 render tests pass; the added helper test covers 72 combinations of sizes/tails/spare capacity, plus malformed checks.

Actual WASM has 74 fresh-instance cold decodes and 56 own-variant repeat decodes (130 allocation measurements); all output checks pass, tracked live bytes after Bitmap drop are zero, and accounting underflow is zero. Four pairs of 21 interleaved warmed timings add 168 calls, with status/live/accounting checks. Inputs remain allocated at constant sizes outside tracked decode metrics; reported linear-memory pages include those inputs. JS output copies do not allocate in WASM. Counters measure requested live bytes; moved-realloc overlap is a conservative estimate, not a direct simultaneous memory sample. Timing includes diagnostic allocator overhead and excludes JS output-copy/hash work.

For current 1024² random and opaque fixtures the candidate reduces final cold WASM capacity by 33 pages (2162688 bytes); 512² random saves 9 pages and 511² remains unchanged. The 1024² moved-overlap estimate falls from 8402728 to7354152 bytes. Own-variant repeats preserve the page difference. Warm timing medians vary: 1024² random 23.571→25.022ms, opaque22.470→26.888ms;512²6.464→6.474ms;511²8.080→7.588ms. These are measured samples, not speed guarantees.

Host tests report one retained48B observation at first RGB-511-random baseline invocation; global initialization is a hypothesis, not a proven allocation attribution. No counter underflows occurred. WASM cold cases did not reproduce it.

This probe uses actual ruffle_render JPEG decode with the default wasm allocator, but lacks the complete web engine feature union, transforms and runtime heap. Node is not WebKit/iOS. No WebGL, GPU, iPhone RSS, app package, CI or release acceptance follows from these results. Full WebGL comparison is the next gate.
