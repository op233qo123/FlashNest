# Bounded synthetic native CWS scene transition diagnostic

Two cases only (tiny, sized), one device/policy, same WK and same AVM2 Loader inside each case. Old child first ENTER_FRAME event plus INIT/COMPLETE precede one unload and new load. Production App, engine/WASM, security config, previous controls, and full-native acceptance are unchanged. This does not reproduce the private game's scripts/graphics or establish OOM/root cause.

## Reproducible fixture closure

`as/SceneParent.as`, `as/SceneChild.as` compile to shipped small `abc/*.abc`. Existing frozen Ruffle ASC tool SHA and playerglobal import SHA are in compiler-provenance.json. Java21 locally compiled both twice byte-identically. `compile_abc.py --asc PATH --imports PATH` verifies regeneration; no compiler download is needed for native CI, which uses these exact reviewed ABCs. Compiler source/API references are the frozen Ruffle tools/asc and tests/framework compiler.

`python generate_fixtures.py --out DIR` verifies source/ABC pins, generates six synthetic SWFs, independently zlib-decodes and parses their tags, and requires exact equality with fixture-manifest.json. Large binaries are LOCAL GENERATED OUTPUTS, NOT publication payload. Only source, small ABCs and manifests are published. No private screenshot/game input.

Encoding is explicitly implemented RFC1950/1951: stored pseudorandom prefix blocks, fixed-Huffman zero-run/tail, Adler32 checksum. hashlib.shake_256 has a fixed public seed. No system zlib compressor/version participates in generated bytes; zlib is solely the independent decoder/checksum. All declared sizes equal actual decoded sizes. Known DefineBinaryData tag exercises tag registration, with no ByteArray instantiation or texture/GPU allocation request; it is not realistic game resource pressure.

Sizes (compressed/decoded): tiny parent2252/2227, children34016/65536 each; sized old12591323/13631488, new45126075/50331648 bytes. Total compressed package <64MiB. CI should generate once and share/copy the same pinned bytes into its two case folders, not store giant Git blobs. Exact hashes in fixture-manifest.json.

## Observation boundaries

Original shell allowScriptAccess=false remains; fixtures emit at most15 `SCENE_PHASE ` JSON traces, no ExternalInterface. Native Host records them through original trace hook; suppressed/overflow traces fail observation integrity. First-frame and INIT are independent: actual local Ruffle may deliver first-frame BEFORE INIT. No opposite order is invented. UNLOAD return/event is not memory reclamation.

`observer.js` is staged-only document-start, associates synthetic main/old/new original fetch Responses through WeakMap. Original receivers/args/Promise/results/errors retained, no response clone/second read/buffer copy/reference retention. Exactly three body fulfillments must match actual compressed fixture sizes. It adds Promise reactions and can alter unhandled-rejection observation; same Promise does NOT mean no semantic observation effect. Explicitly reported. Untracked operations bypass observation. Body records bounded32. It cannot observe WASM copy/decompression, and neither Loader progress nor HTTP200 is used as a substitute.

## Verification / runner interface

`verify_phases.verify_native(out, expected_identity, fixture_manifest_path)` consumes scene-loader-controls.log markers and matching JSON attachments/scene-loader-controls; external identity is mandatory. Returns a rich report even for partial/failing evidence, including raw observations, case summaries, last AS/body phase, termination and errors. No record is upgraded to full-native/render acceptance. Complete diagnostic requires exact two cases, same WK/epoch1, iOS18.2/DPR2, actual Automatic/Original/default-quality load and observed WASM filename in external runtime inventory, fresh final JS snapshot, three exact body lengths, bounded unmodified histories, independent first-frame/complete and single unload. Active window≤120s, final evidence overhead≤10s separately; original timeout error cannot be erased by late completion. Runner owns fixed device/actual policy/source binding and primary XCTest/extraction error preservation.

`verify_cases` is the in-memory equivalent. `verify_as` validates AS semantic milestones, not a Flash golden. `evidenceValid`/`transitionComplete` are scoped to this diagnostic; `nativeAcceptance` and `renderHealthCertified` always false.
