# FlashNest

iOS Flash 模拟器，基于 Ruffle。支持从「文件」导入文件夹、ZIP 或 SWF，保留多 SWF 项目及相对路径资源，并选择入口文件。

- 平台：iOS 17+，iPhone / iPad；仅开发 iOS 应用，不提供桌面版或网页产品。
- 下载：[iOS Preview](https://github.com/op233qo123/FlashNest/releases/tag/ios-preview-20261026)。未签名 IPA 需要自行签名后安装。
- 已完成 iPhoneOS 构建及 17 项模拟器测试，覆盖文件夹/ZIP、多 SWF、文本资源与离线拦截；尚未进行实体设备或真实游戏验证。Flash 兼容性取决于 Ruffle。
- 构建与测试：[说明](scripts/README.md)。不附带第三方游戏。
