# FlashNest

iOS 17+ Flash 模拟器，基于 Ruffle，适用于 iPhone / iPad。仅开发 iOS 应用。

- [下载 1.3 未签名 IPA](https://github.com/op233qo123/FlashNest/actions/runs/40314132327/artifacts/12645353760)：需登录 GitHub，下载 ZIP 后取出 IPA；产物保留至 2026-11-02。安装前需自行签名。
- 导入完整文件夹、ZIP 或 SWF；递归保留所有子目录和相对路径资源，再选择主 SWF。
- 备用导入：把完整游戏文件夹复制到「文件 → 我的 iPhone → FlashNest → Import」，在应用内选择「从应用文件夹导入」并刷新。
- 提供中文、English 和跟随系统选项。不附带第三方游戏。
- 1.3 已通过 29 项核心测试及 iOS 18.2 的 2 项跨应用文件夹选择界面测试。真机导入效果仍待用户确认；游戏兼容性取决于 Ruffle。
