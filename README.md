# FlashNest

iOS Flash 模拟器，基于 Ruffle。支持从「文件」导入文件夹、ZIP 或 SWF，保留多 SWF 项目及相对路径资源，并选择入口文件。

- 平台：iOS 17+，iPhone / iPad；仅开发 iOS 应用，不提供桌面版或网页产品。
- 下载：[iOS 1.1 Preview](https://github.com/op233qo123/FlashNest/releases/tag/ios-v1.1-preview)。未签名 IPA 需要自行签名后安装。
- 1.1：新图标、中英文界面、递归文件夹选择与导入进度。iPhoneOS 构建及 24 项模拟器测试通过；实体设备文件夹导入问题仍待用户复测，真实游戏尚未验证。Flash 兼容性取决于 Ruffle。
- 构建与测试：[说明](scripts/README.md)。不附带第三方游戏。
